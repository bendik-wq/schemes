# Operator: Claude Code for grunnleggere og bedrifter

**Løfte:** «Bygg om hele bedriften din med Claude Code. Kutt hundretusener i programvare og byråer, og bygg en GTM-maskin som åpner nye inntektskilder.»

Nettside: `claude-code-site/` (EN på `/`, NO på `/no/`). Eget Cloudflare-prosjekt.

## To utfall vi selger

| SPAR | VOKS |
|---|---|
| Erstatt SaaS-verktøy, byråer og utviklere med egne verktøy bygget med Claude Code | Bygg en komplett GTM-maskin: VSL-sider, søknadsfunnels, Meta-annonser med server-side-sporing (CAPI), salgsdashboard |
| Typisk kutt: **$100–500k/år** (byrå $5–30k/mnd, dev-byrå $100–300k per prosjekt, SaaS $2–20k/mnd) | Nye inntektskilder: nye tilbud, nye markeder og nye kanaler, lansert på dager, ikke kvartaler |

> Vi lover ikke inntekt. Vi lover at systemene er bygget og i drift, og vi viser regnestykket.

## Operator-stacken (6 moduler)
1. **Fundament:** Claude Code-oppsett, repo, CLAUDE.md, skills-bibliotek (SEO, annonser, copy, salg), hooks, sikkerhetsrammer, deploy til Cloudflare.
2. **VSL- og funnelmotor:** VSL-sider, søknadsskjema i flere steg, takkesider, A/B-testing. *Som denne siden, bygget på dager.*
3. **Sporing og attribusjon:** Meta Pixel + Conversions API (server-side), UTM-arkitektur, lead-scoring, kvalifisering og booking.
4. **Annonsemotor:** Meta-annonser (kreativ, copy, testing og rapporter) med annonseskills. Konkurrentanalyse fra Ads Library.
5. **Salgssystem:** dashboard (show-up, lukkerate, CAC, ROAS, pipeline), AI-analyse av salgssamtaler, oppfølgingsagenter.
6. **Erstatt programvare og byrå:** interne verktøy, kundeportaler, rapportering, automasjoner. Det dere i dag betaler andre for.

## Format
- **Uke 0:** vi setter opp miljøet og stacken for dere (gjort for dere)
- **2 Build Days live:** VSL-side + sporing i drift på dag 2
- **8 ukers kohort** (maks 8 bedrifter): ukentlig byggesesjon og review
- **8 × 1:1** med senior AI-ingeniør på *deres* prosjekter
- **Sikkerhetsgjennomgang** av alt før produksjon
- **90 dagers support** + livslang tilgang til skills-biblioteket
- **2 seter** (grunnlegger + én fra teamet)

## Garantier
1. **7 dager pengene tilbake:** er du ikke overbevist innen 7 dager etter oppstart, får du alt tilbake, uten spørsmål.
2. **Byggegaranti:** VSL-side, sporing og minst 2 interne verktøy i drift innen dag 56, ellers fortsetter vi gratis til de er det.

## Risiko og ærlighet
